Thank you for your interest in **OctalWeb**!

OctalWeb is the official OctalMesh company website. This repository is
maintained and developed by the OctalMesh team. We appreciate your feedback and
bug reports—they help us keep the site reliable, performant, and accessible.

## Before You Start

> [!IMPORTANT]
> OctalWeb is primarily maintained internally. External contributions are
> limited to bug fixes, documentation updates, and accessibility improvements.
> For significant feature requests or design changes, please open an issue to
> discuss first.

When reporting an issue or suggesting an improvement, please include:

- Clear description of the problem or suggestion
- Steps to reproduce (for bugs)
- Screenshots or examples when applicable
- Information about your environment (browser, device, OS)

## How You Can Contribute

You are welcome to:

- **Report bugs** (broken links, layout issues, performance problems,
  accessibility barriers)
- **Suggest improvements** (usability, accessibility enhancements, minor UI
  refinements)
- **Update documentation** (README, guides, typo fixes)
- **Request clarification** regarding website behavior or content

Please use [GitHub Issues](https://github.com/OctalMesh/OctalWeb-Links/issues)
to share your feedback.

## Pull Request Guidelines

Pull requests are reviewed case-by-case. We generally accept:

- Bug fixes for reported issues
- Documentation updates and typo corrections
- Accessibility improvements
- Performance optimizations

We do not accept:

- Pull requests for major design changes or new features
- Bulk or automated modifications without prior discussion
- Substantial rewrites of content or code

If you're working on a significant change, please open an issue first to discuss
the approach with the team.

## Code of Conduct

By participating in this project, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
