Дякуємо за ваш інтерес до **OctalWeb**!

OctalWeb є офіційним вебсайтом компанії OctalMesh. Цей репозиторій підтримується
та розвивається командою OctalMesh. Ми цінуємо ваш зворотний зв'язок та звіти
про помилки, вони допомагають нам підтримувати сайт надійним, продуктивним та
доступним.

## Перш ніж розпочати

> [!IMPORTANT]
> OctalWeb в основному підтримується внутрішньо. Зовнішні внески обмежені
> виправленнями помилок, оновленнями документації та поліпшеннями доступності.
> Для значних запитів на функції або змін дизайну, будь ласка, спочатку
> відкрийте issue для обговорення.

При повідомленні про проблему або пропозиції покращення, будь ласка, включіть:

- Чіткий опис проблеми або пропозиції
- Кроки для відтворення (для помилок)
- Скріншоти або приклади, якщо це доречно
- Інформацію про ваше середовище (браузер, пристрій, ОС)

## Як ви можете допомогти

Ви можете:

- **Повідомляти про помилки** (непрацюючі посилання, проблеми з версткою,
  проблеми продуктивності, перешкоди доступності)
- **Пропонувати покращення** (зручність використання, поліпшення доступності,
  незначні UI-вдосконалення)
- **Оновлювати документацію** (README, посібники, виправлення опечаток)
- **Запитувати роз'яснення** щодо поведінки або вмісту вебсайту

Будь ласка, використовуйте
[GitHub Issues](https://github.com/OctalMesh/OctalWeb-Links/issues) для того,
щоб поділитися своїм зворотним зв'язком.

## Рекомендації щодо Pull Request

Pull request-и розглядаються в індивідуальному порядку. Ми в основному приймаємо:

- Виправлення помилок для повідомлених проблем
- Оновлення документації та виправлення опечаток
- Поліпшення доступності
- Оптимізація продуктивності

Ми не приймаємо:

- Pull request-и для значних змін дизайну або нових функцій
- Масові або автоматизовані модифікації без попереднього обговорення
- Значні переписування контенту або коду

Якщо ви працюєте над суттєвою змією, будь ласка, спочатку відкрийте issue для
обговорення підходу з командою.
