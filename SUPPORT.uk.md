## Яка підтримка надається

Ми надаємо підтримку, орієнтовану на спільноту, для:

- Звітів про помилки з чіткими кроками відтворення
- Відтворюваних технічних проблем
- Виправлень і уточнень документації
- Чітко сформульованих пропозицій щодо функціональності

## Що не вважається підтримкою

| Не надається                                       | Причина                              |
|----------------------------------------------------|--------------------------------------|
| Підтримка в реальному часі або через чати          | Немає виділеного персоналу підтримки |
| Приватна індивідуальна допомога                    | Модель, орієнтована на спільноту     |
| Перегляд архітектури або дизайну                   | Виходить за межі issue-трекера       |
| Налагодження форків або суттєво змінених баз коду  | Занадто багато змінних               |
| Розробка кастомних функцій                         | Це не консалтингова послуга          |
| SLA або гарантовані строки відповіді               | Лише підтримка на основі зусиль      |

## Де ставити запитання

> [!TIP]
> Оберіть правильний канал - це допомагає всім рухатися швидше.

| Тема                                      | Канал                                                                           |
|-------------------------------------------|---------------------------------------------------------------------------------|
| **Помилки та запити на функціональність** | [Відкрийте issue](https://github.com/OctalMesh/OctalWeb-Links/issues) на GitHub |
| **Загальні запитання та обговорення**     | [GitHub Discussions](https://github.com/OctalMesh/OctalWeb-Links/discussions)   |
| **Вразливості безпеки**                   | Дотримуйтесь [`SECURITY.md`](SECURITY.md) - **не повідомляйте публічно**        |

## Перед створенням issue

> [!IMPORTANT]
> Малоінформативні, нечіткі або не на тему issues можуть бути закриті без
> відповіді.

Будь ласка, переконайтеся, що ви:

- [ ] Перевірили наявні issues
- [ ] Можете стабільно відтворити проблему
- [ ] Додали чіткі кроки відтворення
- [ ] Додали відомості про середовище або конфігурацію
